# RealBugz QA Testing Project

Personal QA practice project focused on manual testing of the RealBugz web application and identifying intentionally introduced defects.

The project includes test case design, functional testing, positive and negative testing, and structured bug reporting.

A total of 16 test cases were created and executed, resulting in 11 documented defects.

The repository contains the QA testing report, the Excel file with test cases and bug reports, and the Postman collection used for API testing.

This project was created to practise and demonstrate my practical Quality Assurance skills.
